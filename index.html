O-HYPE bot プライバシーポリシー

最終更新日: 2026年9月10日

1. はじめに

本ポリシーは、Discord アプリケーション「O-HYPE bot」（以下「本Bot」）が、Discord API を通じて取得・保存する情報の取扱いを説明するものです。本Botは、ゲーム体験の改善を目的としたコミュニティ運営（イベント企画・告知の効果把握、参加・定着の評価、サーバー内活動に応じたポイント連携）のために利用されます。

運営者: 株式会社NERDER
連絡先（開示・訂正・削除の窓口）: support@nerder.jp

本Botを導入した Discord サーバーに参加すると、本ポリシーに記載する範囲で情報が処理されることがあります。

2. 取得する情報

本Botは、導入先サーバーのメンバーおよび、サーバー内で本Botが検知できる活動に関する情報を取得します。メッセージの本文、添付ファイル、embed、オンライン状態（オンライン / アイドル / オフライン）、プレイ中のゲームなどの Presence 情報は取得しません。パスワードその他のログイン情報も取得しません。

(1) サーバー在籍・プロフィール（ギルドメンバー情報）

サーバー全メンバーを定期取得し、次を保存します。

  • Discord ユーザー ID
  • Discord ユーザー名、discriminator、タグ
  • サーバーニックネーム
  • サーバー参加日時（joined_at）
  • サーバーブースト開始日時（該当する場合）
  • アバター画像の識別子（ハッシュ）、バナー情報
  • Bot アカウントかどうかのフラグ
  • サーバー（ギルド）ID

(2) 参加・再加入・離脱の記録

同じく全メンバーの定期取得に基づき、次を保存します。

  • Discord ユーザー ID、サーバー ID
  • 参加日時
  • 在籍を確認した日時（last_seen_at）
  • 再加入回数、再加入までの間隔

一覧に現れなくなったメンバーは、在籍確認日時が更新されないことにより離脱として扱います。発言の有無は問いません。

(3) サーバー内活動（ポイント連携）

本Botは、次の活動の「有無と発生場所・時刻」を記録します。メッセージ本文は保存しません。

  • チャンネルへの投稿があったこと（投稿者のユーザー ID、サーバー ID、チャンネル ID、検知日時）。本文・画像・リンク先の内容は保存しません。
  • リアクションしたこと（ユーザー ID、サーバー ID、対象メッセージ ID、検知日時）
  • ボイスチャンネルへの入退室、滞在、ミュート / スピーカーミュートの状態、チャンネル ID、時刻
  • 特定名称のボイスチャンネルへの参加ログ

(4) 本Botから送るメッセージ

運営からの通知のため、既に把握しているユーザー ID 宛てに Discord の DM を送ることがあります。送信する本文は運営側システムが用意したものです。ユーザーが本Botに送った DM の本文を、特権インテントで読み取る運用はしていません。

3. 利用目的

取得した情報は、次の目的に限り利用します。

  • 導入サーバーの在籍者ディレクトリの維持（表示名、参加日、ブースト状況などの最新化）
  • イベント企画の改善、および告知が参加・定着・離脱・再加入（オンボーディング）に与える影響の評価
  • コミュニティの参加数・離脱数などの集計（個人を特定しない形の分析を含む）
  • サーバー内活動に応じたポイントの記録・表示・管理者による付与 / リセット
  • 本Botの運用、障害対応、不正利用の防止、Discord の規約遵守

メンバー一覧を、宣伝メール、第三者への販売、無関係な広告配信の宛先抽出には使いません。告知は Discord サーバー内のチャネルで行います。

4. 保存場所と保管期間

情報は、株式会社NERDER が管理するサーバーおよびデータベース（クラウド上のインフラを含む）に保存します。Discord 上だけに置くのではなく、運営者のシステムへ複製して保管します。

保管期間は、上記利用目的に必要な期間とします。本Botの利用を終了した場合、または削除依頼を受けた場合は、法令上の保管義務がある場合を除き、合理的な期間内に削除または識別できない状態にします。

5. 第三者提供・委託

Discord API の利用に伴い、情報は Discord, Inc. のサービスを経由します。Discord 側の取扱いは Discord のプライバシーポリシーに従います。

運営者は、サーバー・データベース・分析などのインフラ提供事業者に、本目的の範囲で処理を委託することがあります。

ユーザーの指示なく、API で得た個人データを上記以外の第三者へ販売・提供しません。

6. ギルドメンバーインテントについて

本Botは、沈黙メンバーを含む在籍の把握、参加日時の変化による再加入の記録、一覧にいないメンバーの離脱把握、および在籍ディレクトリの同期のため、Discord の Guild Members Intent（サーバーメンバー一覧の取得）を使用します。メッセージ本文用の Message Content Intent、およびオンライン状態用の Presence Intent は、本機能では使用しません。

7. 開示・訂正・削除

ご自身の情報の開示、訂正、削除を希望する場合は、support@nerder.jp まで、Discord ユーザー ID（分かる場合）とご依頼内容をご連絡ください。本人確認のため、追加の確認をお願いすることがあります。

サーバーから退出しただけでは、運営者側の記録が直ちに消えない場合があります。削除を希望する場合は上記窓口へご連絡ください。

8. 安全管理

運営者は、不正アクセスや漏えいの防止のため、アクセス制限や通信の暗号化など、合理的な安全管理措置を講じます。

9. 本ポリシーの変更

取得項目や利用目的に重要な変更がある場合は、本ポリシーを更新し、最終更新日を改めます。最新版は本ページで確認できます。
